# 《香港散步學》十条路线核对与扩展 · 2026-11-16

基于豆瓣读者 Eeyore 按黃宇軒《香港散步學》（白卷出版，2022）手工标记的 11 张 Google My Maps（`#0 起點總圖` + `#1–#10 十条路线`），完成 KML 原始数据归档、顺序交叉核查、OpenStreetMap 代表点独立检索及 FOSSGIS OSRM `routed-foot` 真实步行路网接入。

当前项目共 **25 个片区、132 个地点、26 条路网核对路线**（另有 5 个片区保留在 `planned-areas.json`）。原有 16 个片区、59 个地点与 16 条路线的 ID 及浏览器本地记录键完全保留。

## 一、 原始 Google My Maps KML 归档清单

全部 11 张地图均公开可访问，原始 KML、汇总 CSV 与 JSON 已归档于 `data/raw/hk-strollology/`（仅供本地比对研究，前端不加载 Google POI 坐标）：

- `data/raw/hk-strollology/hk_strollology_routes.csv`（97 行，含每点备注与顺序存疑说明）
- `data/raw/hk-strollology/hk_strollology_routes.json`（11 张地图结构化数据）
- `data/raw/hk-strollology/kml/route_00_origins.kml` ～ `route_10_tsuen_wan_sham_tseng.kml`

### 读者地图核查关键发现

1. **路线 1（大坑）顺序交叉验证**：读者地图显示的钉点顺序（`1.皇仁書院-八顆吉貝` → `2.火龍徑` → `3-4.第二巷4號` → `5.融苑` → `6.利群道建築` → `7.虎豹別墅` → `8.勵德邨` → `9.通往蓮花宮公園的樓梯` → `10.蓮花宮公廁`）与二手文字中的**「列表版」完全吻合**（先上山至虎豹别墅、励德邨，再下山至莲花宫）。
2. **路线 2（宝马山➡️北角）**：读者地图第 7 点（和富商场）由百福道直接西跳约 1 公里至海边，第 8、9 点又折返东南方向的锦屏街与明园西街，第 10 点再折返北角码头。接入项目时已按顺路步行修正为：百福道交通安全城 → 锦屏街 → 明园西街 → 和富中心 → 北角（西）渡轮码头 → 北角站。
3. **路线 3（西半山）**：读者地图将 `2.大學道一號附近的八角形鐵水箱` 错排在 KML 第 8 位（紧邻第 1 点龙虎山环境教育中心东侧 184 米，却排在己连拿利天桥之后）。接入项目时已按真实自西向东顺序修正。
4. **路线 7（土瓜湾）**：读者地图漏掉 `5.` 号点，且在第 8 点（`9.高山劇場及公園`）与第 9 点（`10.新亞中學`）之间南北折返 786 米。接入项目时由港铁土瓜湾站出发，先走南侧高山剧场、靠背垄道游乐场、乐民新村、土瓜湾街市，再向东/北走海心公园、牛棚艺术村、新亚中学，于宋皇臺站结束。

## 三、 重建与校验命令

```sh
python3 scripts/expand-strollology.py
python3 scripts/enrich-photos.py
npm run check:data
npm run check:recommend
npm run build
```
