## 三条优先示范

1. **浅水湾—赤柱**：已核对 OSM 两段步行、运输署 260 道路几何及站序；1,737 米步行，24 分钟模型估时，另有 4,641 米巴士段。快照不是当天通行保证。
2. **上环—西营盘**：西港城—荷李活道公园—西营盘站；1,210 米、17 分钟模型估时；路网原始响应与地图截图留存。
3. **长洲**：码头—北帝庙—东湾—码头，1,259 米、17 分钟模型估时；中环 5 号码头—长洲接驳引用新渡轮；没有伪造海上航迹。

## 验收边界

浏览器测试为桌面 Chromium 的响应式视口，不是实体 iPhone/Android 或 Safari 测试。未做野外实测、坡度/轮椅可达性审核、定位授权真机测试、长期瓦片稳定性或低端设备性能跑分。路线的核实级别在 UI 中有明确说明，不将静态路网算路当作实地 GPS。

仍需后续工作的 13 个规划片区、渡轮/地铁真实航迹、实时状态、无障碍证据和文化内容列在 README；没有用假数据填满这些项目。

生产预览补充：通过 Vite preview 的 4178 端口验证静态产物，独立 worker 资源成功请求，混合路线和主题切换无控制台错误。开发预览在 5178 端口供本地查看。


## 地点游玩指南补充验收（2026-11-02）

42 个地点均有游玩区间、具体看点、分步骤公共交通、来源与核对日期。25 个游览点使用停留区间，17 个交通节点不计固定游玩时长。数据完整性检查及生产构建通过。路线节点与片区地点列表展示各点停留信息；外部公交链接设置 travelmode=transit。

补充浏览器检查通过：元创方 45–90 分钟、交通出口与看点展示；手机公共交通步骤及外部 transit 链接；浅水湾巴士站显示交通节点而非 0 分钟游玩；中环路线节点显示元创方和大馆的时长、看点。390 像素无横向溢出，采集到的控制台 errors=[]。截图：`place-guide-desktop.png`、`place-guide-mobile.png`。


## 线路优先显示调整
