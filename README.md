# 香港与深圳漫游 · Hong Kong & Shenzhen Wandering

一个地图主导的双城本地漫游探索工具（香港 / 深圳切换）。React + TypeScript + Vite + MapLibre GL JS + OpenFreeMap；无需后端、账户或 API key。仅本地实现，未部署。

## 启动

需要 Node.js 22.18+。

```sh
npm ci
npm run dev -- --port 5178
```

打开 http://127.0.0.1:5178 。底图需要联网；内容、路线几何与记录逻辑不依赖远程业务 API。

```sh
npm run build
npm run check:data
npm run check:recommend
npm run preview -- --port 4178
```

## 仍有限制

- 未进行实地踏查，未获取逐段坡度、楼梯/无障碍、施工及室内开放约束。大馆/半山扶梯段尤其需要现场确认；地点可能是建筑/沙滩代表点。
- 不含实时天气、客流、巴士 ETA、票价、场馆营业时间；地图与静态接驳不能替代现场导航。
- 渡轮作为外部接驳说明，未绘制航行轨迹；线路渲染已支持渡轮/地铁线型，但没有假造这些交通几何。
- “雨天可玩”“适合独自出行”尚无充分证据标签，选择后可能无匹配；不把未知条件当满足。“少爬坡”仅匹配 `climbLevel: "flat"` 平缓路线。
- 出发点排序只用直线邻近，不估计港铁/渡轮转乘成本。游玩时间不含出发地至片区的往返。
- 已去过与路线完成是独立记录，不自动合并；记录只在当前浏览器，清除数据会丢失。
- 地图需联网，未做离线瓦片包。MapLibre 主包较大，已独立分包方便缓存；没有离线可用或低端真机性能保证。
- 文化内容仅预留模型（已覆盖全部 32 个规划片区）。

不得自动部署；本项目没有注册站点、上传源码或执行发布。

路线支持多标签，详情显示归类理由；编辑源在 `data/editorial/route-categories.json`。基础数据重建后，最后运行 `python3 scripts/classify-routes.py` 恢复特色标签。

## 交通点连接（2026-11-02）

11 条路线均以交通点为起终点，支持港铁、巴士、码头；同站往返合并显示「起 / 终」。选中路线后才显示交通节点，概览仍以线路为主。油麻地线路经佐敦站提供中途接入；浅水湾线路注明上车、下车及赤柱回程站。沿途列表显示逐段实际路网距离与模型步行估时，公交段不编造车程。

`transportNodes` 保留角色、交通方式、服务、方向、来源与行程序号；`itineraryLegs` 保留逐段距离。运行 `python3 scripts/connect-transit.py` 可使用已缓存路由重建，政府站点使用 `data/raw/td-route-endpoints.geojson`。首次重新获取政府全量数据时，使用官方 JSON_BUS.json，原始查询结果保留在 data/raw。

港铁为 OSM 车站代表点，不保证具体出口或无障碍通道；站内步行与候车船不计入路线估时。没有覆盖全港所有交通站点，南丫岛跨岛中段未标巴士或港铁接出点。每条新增步行连接均有独立 OSRM 响应，未使用直线连接。
